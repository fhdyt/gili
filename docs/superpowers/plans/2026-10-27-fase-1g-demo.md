# Fase 1g: Mode Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Menu klik kanan bar punya `Demo mode` yang memutar skenario palsu sekitar 30 detik melewati semua keadaan pulau Fase 1, lalu mengembalikan keadaan asli.

**Architecture:** Skenario dan pemutarnya ada di `Gili.Core.Demo` sebagai data yang dites (`DemoScript`, `DemoPlayer`). `Gili.App` punya `DemoService` yang menjalankan pemutar tiap 100 ms dan menyuntikkan langkahnya ke celah yang sudah ada: media palsu ke `MediaService`, daya palsu ke `IslandController`, buka/tutup halaman ke `IslandController`. Selama demo, pembacaan asli tetap jalan tapi tidak tampil; setelah demo, keadaan asli dipasang lagi.

**Tech Stack:** .NET 10 WPF, xUnit.

**Spec:** [PRD](../specs/2026-10-25-top-taskbar-prd.md) F-BAR-09, 6.1 (menu klik kanan: Open Tools, Settings, Demo mode, Quit), 9.x ("mode demo memakai implementasi palsu"), 13 (mode demo untuk memeriksa tampilan dan gerak); mockup JS `DEMO` (baris ±3335).

## Global Constraints

- Teks UI: item menu `Demo mode` (tercentang selama demo berjalan; klik lagi menghentikan). Lagu palsu `Midnight City` · `M83`, aplikasi `Spotify.exe`, durasi 4:03, mulai di 0:42.
- Demo tidak pernah mengubah sistem: tidak menyentuh volume, media asli, atau setting. Tombol media di pulau saat demo tidak mengirim perintah ke aplikasi asli.
- Setelah demo selesai atau dihentikan: pulau tertutup, media dan daya kembali ke pembacaan asli terakhir dalam 1 detik.
- Anggaran PRD 8.1: demo hanya memakai timer 100 ms selama berjalan; 0 saat tidak berjalan.

## Keputusan yang dibuat di rencana ini

1. **Celah, bukan interface baru.** Belum ada provider di Core; demo menimpa `MediaService` dan daya di `IslandController`, dua sumber yang menggerakkan pulau Fase 1. Interface provider Core dibuat bersama provider baru di fase berikutnya, dan demo memakai interface itu sejak saat itu.
2. **Hanya keadaan yang sudah ada di Fase 1**: musik di slot dan Gili pindah ke lingkaran, charger masuk (wide + gelembung), halaman Media, pindah tab (Timer, Calendar, Todo), pulau Power, charger keluar, musik jeda lalu hilang (Gili kembali ke pulau). Copy, drop Shelf, notifikasi, dan Claude ditambahkan saat fiturnya ada.
3. **Sampul palsu** dibuat App sebagai gradasi ungu–biru 300 × 300 (PNG di memori) supaya glow halaman Media mendapat warna; Core memakai `Cover: null`.

## Review Focus

1. **Musik asli sedang diputar saat demo mulai**: demo menimpanya; setelah demo, slot kembali menampilkan lagu asli tanpa menunggu event baru. Diperiksa manual (Spotify diputar).
2. **Charger dicabut/dicolok sungguhan saat demo**: tidak tampil selama demo; setelah demo, keadaan charger asli yang tampil. Dites di Task 2 lewat urutan `EndDemo` yang membaca ulang `PowerMonitor.Read()`.
3. **Demo dihentikan di tengah** (klik `Demo mode` lagi saat pulau Power terbuka): pulau tertutup, tidak ada langkah tersisa yang jalan sesudahnya.
4. **Tombol play/pause di pulau saat demo**: tidak memengaruhi aplikasi asli.
5. **Fullscreen saat demo**: pulau tersembunyi seperti biasa; demo tetap berjalan dan berhenti normal.

### Task 2: Demo di app

**Interfaces:**
- Consumes: `DemoScript.Phase1`, `DemoPlayer`, `DemoAction` turunan (Task 1).
- Produces:
  - `MediaService.SetDemo(MediaState? state)` (selama demo `Current` = state ini, `TogglePlayPauseAsync/NextAsync/PreviousAsync/SeekAsync` tidak memanggil sesi asli) dan `MediaService.EndDemo()` (kembali ke sesi/VLC asli dan langsung `Publish()`).

  - `DemoService(Dispatcher, IslandController, MediaService)` dengan `bool IsRunning`, `void Toggle()`, `event Action? Changed`.
  - `BarWindow.DemoRequested` (event) dan `BarWindow.SetDemoRunning(bool)` (centang menu).

- [ ] **Step 1:** seam `MediaService` dan `IslandController` sesuai Interfaces. Wide charger saat `EndDemo` tidak muncul: pasang snapshot asli sebagai "sebelumnya" lalu panggil aturan seperti biasa.
