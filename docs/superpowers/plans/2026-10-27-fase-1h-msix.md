# Fase 1h: Paket MSIX Dasar Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `pwsh scripts/package.ps1` membangun paket MSIX self-contained Gili yang bisa dipasang dan dijalankan di laptop pengembang, dan Gili berperilaku benar di dalam paket: folder data di folder lokal paket dan autostart lewat `StartupTask`.

**Architecture:** `Gili.Core.AppPaths` menghitung folder data dan jenis instalasi sebagai fungsi murni yang dites. `Gili.Platform.Shell.PackageInfo` membaca identitas paket (`GetCurrentPackageFullName`) dan folder lokal paket; `PackagedStartup` membungkus `Windows.ApplicationModel.StartupTask`. `App` memilih folder data dan cara autostart dari jenis instalasi. `scripts/package.ps1` menjalankan `dotnet publish` self-contained win-x64, menyalin `packaging/AppxManifest.xml` dan `packaging/Assets`, lalu `makeappx pack`; `-Install` mendaftarkan layout lewat `Add-AppxPackage -Register`.

**Tech Stack:** .NET 10, Windows SDK 10.0.19041 (`makeappx.exe`), PowerShell 7, xUnit.

**Spec:** [PRD](../specs/2026-10-25-top-taskbar-prd.md) F-PUB-01 (Fase 1: paket dasar), 9.4 (Store: `runFullTrust`, `StartupTask`, versi `MAJOR.MINOR.PATCH.0`), 10 (folder data MSIX = `ApplicationData.Current.LocalFolder`); CLAUDE.md (Distribusi, Hak akses).

## Global Constraints

- Tanpa admin dan tanpa UAC, termasuk saat memasang. Tidak memasang sertifikat ke store mesin; pemasangan lokal memakai pendaftaran layout (butuh Developer Mode yang dinyalakan pengguna sendiri).
- Self-contained win-x64; tanpa obfuscation atau packer.
- Identitas paket pengembangan: `Name="Gili"`, `Publisher="CN=Gili Dev"`, `ProcessorArchitecture="x64"`; versi dari `<Version>` di `Directory.Build.props` (`0.1.0`) menjadi `0.1.0.0`. `TargetDeviceFamily Windows.Desktop` MinVersion `10.0.22000.0` (hanya Windows 11).
- Manifest: `EntryPoint="Windows.FullTrustApplication"`, `rescap:Capability runFullTrust`, `DeviceCapability location` (nama Wi‑Fi, F-RIGHT-02), `desktop:StartupTask TaskId="GiliStartup" Enabled="true" DisplayName="Gili"`.
- Teks UI baru persis: `Turned off in Task Manager › Startup apps` (PRD 9.4).
- Versi MSIX tidak pernah menulis `HKCU\...\Run`; data di `%LOCALAPPDATA%\Packages\<paket>\LocalState\`.

## Keputusan yang dibuat di rencana ini

1. **Pemasangan lokal = `Add-AppxPackage -Register` dari layout** (Developer Mode). Alternatif paket bertanda tangan butuh sertifikat dipercaya di `LocalMachine` (admin), yang dilarang Global Constraints. `.msix` tetap dibuat dari layout yang sama untuk Partner Center (Store menandatanganinya).
2. **Aset sementara**: logo 44, 150, dan StoreLogo 50 px digambar dari maskot (kotak hitam radius 22% dengan dua mata putih) oleh `scripts/package-assets.ps1` dan di-commit di `packaging/Assets`; diganti seni final di Fase 5.
3. **Impor data GitHub → Store** (PRD 10) dan installer GitHub masuk Fase 5 bersama F-PUB-01 lengkap.
4. Restart otomatis setelah crash, hotkey, toast, dan perilaku lain di dalam paket diperiksa lewat checklist Fase 1 setelah paket terpasang; temuan dicatat, bukan diperbaiki di rencana ini.

## Review Focus

1. **Developer Mode mati**: `-Install` berhenti dengan pesan yang menyebut cara menyalakannya (`ms-settings:developers`), tanpa mengubah apa pun.
2. **Instance biasa sedang jalan saat versi paket mulai**: mutex F-BAR-05 sama, jadi versi paket membuka Settings di instance lama lalu keluar. Diperiksa manual setelah pemasangan.
3. **StartupTask dimatikan di Task Manager**: saklar `Start with Windows` nonaktif dengan `Turned off in Task Manager › Startup apps`; Gili tidak mencoba menyalakannya. Dites di Task 1 (`Startup_blocked_by_the_user_is_shown_and_never_forced`).
4. **Menjalankan `package.ps1` dua kali**: layout lama dibersihkan dulu; paket terdaftar lama diganti (`-ForceUpdateFromAnyVersion`).
5. **Build biasa (`dotnet run`, salinan terpasang) tidak berubah**: folder data tetap `%LOCALAPPDATA%\Gili\`, autostart tetap Run. Dites di Task 1.
